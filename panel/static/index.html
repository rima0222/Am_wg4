Admin settings

Fair bandwidth sharing

No per-user caps. When the server is idle everyone gets full speed; when it is busy, bandwidth is shared fairly per user, so a heavy downloader cannot slow light users. Applied live - nobody is disconnected.

Server domain / address

The address written into every client config's Endpoint line. Change this after moving to a new server or pointing a domain at it — takes effect immediately for new configs.
